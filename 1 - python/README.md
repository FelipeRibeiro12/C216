# Gerenciamento de Alunos — Python

## Tech Stack

[![My Skills](https://skillicons.dev/icons?i=python)](https://skillicons.dev)

## Estrutura do diretório

- `aluno.py` — Modelo da classe/entidade Aluno
- `controller_alunos.py` — Controlador responsável pelas regras de negócio e gerenciamento dos alunos
- `main.py` — Ponto de entrada (entrypoint) da aplicação

## Iniciando

1. Certifique-se de ter o [Python 3.x](https://www.python.org/) instalado em sua máquina.

2. Acesse a pasta do projeto no seu comando/terminal:

```bash
cd "1 - python"
```

3. Inicie o sistema executando o script principal:

```bash
python main.py
```
